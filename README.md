# 跳一跳 · 森林

一个单文件 HTML5 小游戏：按住蓄力、松开跳跃，在木柱与弹簧柱之间一路往前跳。
天空会随着分数从白天走到黄昏，分数越高柱子越窄、间距越大。

## 直接玩

用手机浏览器打开 `index.html` 即可，无需服务器、无外部依赖。

- 按住屏幕蓄力，松开跳
- 落在柱子正中 = 完美（+2，连击越高加得越多）
- 绿色弹簧柱 = 额外加分
- 连击、里程碑、霓虹黄昏，都在里面

## 说明

- 全部逻辑在一个 HTML 文件里（Canvas 2D），约 96 KB
- 自适应分辨率：掉帧时自动降档渲染
- 支持全屏 + 横屏、音效/震动开关、本机排行榜（localStorage）
- 排行榜可选接在线接口：用 `?api=你的地址` 打开一次即可记住

## 操作

| 动作 | 说明 |
| --- | --- |
| 按住屏幕 / 空格 | 蓄力 |
| 松开 | 起跳 |
| 右上角按钮 | 静音 / 暂停 / 全屏 |
| P 或 Esc | 暂停 |
